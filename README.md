# 1v1 Football (Open Field)

![Open Field V6 start screen](screenshots/menu.png)

A browser-based **arcade American football game** — dodge defenders, pass to your
wide receiver, and score touchdowns. Built as a single self-contained HTML file
(no build step, just open in a browser).

## Features
- Neon/cyberpunk launch menu with lives and stamina HUD
- Movement (WASD), sprint (SHIFT, drains stamina), and skill moves:
  - `1` Juke · `2` Spin · `3` Truck · `4` Pass to WR
- Start with `ENTER` / `SPACE`
